## 下载与首次使用

下载下方的 **MicCast.exe**，直接运行，无需解压或安装 MicCast。

首次使用需安装 [VB-CABLE 官方驱动](https://vb-audio.com/Cable/)，完成后重启 Windows。程序会自动检查，缺少驱动时提供安装引导。第三方驱动单独安装。

适用于 Windows x64，要求 .NET Framework 4.7.2 或兼容的 4.x 运行时。

## 功能

- 可拖动、置顶的悬浮麦克风：左键开始或停止，右键退出。
- 待机蓝光、扩声红光，银灰色蚀刻图标和明确的状态文字。
- 内置麦克风直送普通双声道 VB-CABLE，供支持捕获 Windows 当前默认输出声音的投屏软件分享。
- 自动切换默认播放设备，停止或退出时恢复三个音频角色；异常退出后再次打开可恢复。

本机两轮音频路由自测通过，处理 34,560 和 34,656 帧，三个默认角色均恢复。各投屏软件的兼容性、大屏实际听感、延迟和教室扩声效果待现场验证。

`SHA256SUMS.txt` 用于校验 EXE；`QUICKSTART.md` 为使用说明。程序未做代码签名。
