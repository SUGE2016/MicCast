# MicCast 快速开始

下载 `MicCast.exe`，直接双击运行。适用于 Windows x64，需要 .NET Framework 4.7.2 或兼容的 4.x 运行时。

首次使用请单独安装 [VB-CABLE 官方驱动](https://vb-audio.com/Cable/)，完成后重启 Windows。缺少驱动时，MicCast 会显示“需安装”并提供官方下载入口。使用普通双声道 VB-CABLE 播放设备；无需手动切换 Windows 默认输出。

连接支持捕获 Windows 当前默认输出声音的投屏软件，开启电脑声音分享，点击桌面右下角的小球开始扩声：

- 蓝光、斜线麦克风、“已关闭”：待机。
- 红光、双层声波、“扩声中”：麦克风链路已启动。
- 再次点击停止；拖动移动；右键退出。

停止或退出会恢复原来的 Windows 默认声音输出。若大屏无声，在扩声开启后重新开关投屏软件的电脑声音分享。先保持较低的大屏音量，再逐步调高。

本机音频路由已通过自测；各投屏软件的兼容性、大屏听感、延迟和现场扩声效果待现场验证。
